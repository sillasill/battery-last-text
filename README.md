A program that writes the phone battery's last text message to the charger it waited for all day — one line, at most 200 characters. Entered in make.fun's "The Battery's Last Text to Its Charger" bounty.

## Run it

```sh
node main.ts
```

Writes the text to `/output/entry.txt`.
